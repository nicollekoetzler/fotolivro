# Oficina de Memórias

Landing page da imersão online **Oficina de Memórias**, da Coração de Papel, em Next.js (App Router).

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Publicar

```bash
npm run build
npm start
```

O projeto também pode ser importado direto na Vercel.

## Onde editar

- `app/page.tsx`: textos e estrutura da página
- `app/globals.css`: estilos
- `public/assets/`: imagens
- `public/videos/`: coloque aqui os vídeos da oficina com estes nomes: `montagem-orientada.mp4`, `criando-juntas.mp4`, `mesa-de-materiais.mp4` e `paginas-em-construcao.mp4`
